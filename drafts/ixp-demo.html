Experiment-assignment (IXP) demo

This page wires Intuit's Decision Engine onto the vendored aem-experimentation plugin's getAssignment hook (scripts/personalization/byo.js), using the frozen-API model: the engine owns the arm (bucketing/stickiness/exposure) AND hands back the variation content itself (assetLocation) for a natively-authored experiment — a Section Metadata block with Experiment / Experiment Variants rows, not a manifest sheet. The Experiment Variants href below is only a placeholder key now (the plugin just needs a truthy variant url to proceed to renderDecision); the content that actually renders comes from whatever getAssignment stashed from the engine's own answer, never from that href.

Try ?experiment=ixp-hero-test/challenger-1 or ?experiment=ixp-hero-test/control to force an arm (the plugin's own QA override — it still wins the plugin's own arm selection/attribution, but now also invokes getAssignment for its resolution side-effect, so the engine's content is still available to render under a forced arm), or no parameter at all to see the mock engine's assignment (sticky per experiment — persisted in an ixp-mock-ixp-hero-test cookie) — reload a few times with no parameter and the same arm keeps showing. Open devtools while loading to confirm there are no console errors.

How this works

The engine owns both the arm AND the content (getAssignment stashes the engine's assetLocation/redirect path, keyed by experiment id); the page's own Experiment Variants metadata is now just a placeholder that lets the plugin's existing arm-vs-control dispatch keep working unchanged. There is no manifest sheet involved here, unlike the placement-resolution demo (pzn-cell-demo.html). This is a section-level experiment: the section above (the control content plus its Section Metadata block) is the control arm, and drafts/fragments/experiments/hero-challenger-1 is the content the mock engine hands back for the sole challenger arm.

See documentation/experiments.md in the vendored plugin for the native authoring convention, and documentation/byo-decision-engine.md for the getAssignment hook contract.
