Cell-resolution personalization demo

This page wires Intuit's decision engine onto the vendored aem-experimentation plugin's bring-your-own manifest mechanism, using the cell-resolution model: the engine (scripts/personalization/byo.js) resolves which audience cell a visitor is in, and the published manifest sheet below owns the cell-to-fragment mapping for each personalizable slot on this page.

Try ?audience=retail, ?audience=hospitality, or no parameter at all (sticky demo mock — persisted in a pzn-cell cookie) to see the hero and offer slots below swap content. Open devtools while loading to confirm there are no console errors.

How this works

The engine owns cell resolution (who is this visitor), and the manifest sheet owns cell-to-content (what does that cell see). Neither the hero nor the offer slot above carries a data-pzn, data-exp, or personalization-id marker, so this page never touches Intuit's existing pzn.js/exp.js path — it exercises only the plugin's own audience-manifest mechanism.

See drafts/pzn-manifest.json for the published sheet, and drafts/fragments/pzn/ for the per-cell fragments it points to.
